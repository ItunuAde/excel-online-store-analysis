Online Store Sales Analysis (Excel)

Summary: Excel project analyzing transaction data to find top products, monthly trends, payment preferences, referral performance and order status distribution.

Files included
- `Online-Store-Orders_Cleaned.xlsx` — cleaned dataset
- `Online-Store-Dashboard.xlsx` — workbook with pivot tables & dashboard
- `Online-Store-Sales-Analysis_Report.pdf` — PDF case study

How to view
Open `Online-Store-Dashboard.xlsx` in Excel and go to the Dashboard sheet. The report PDF summarizes findings and recommendations.

Key insights
- Top products: Chairs, Printers, Laptops
- Customers prefer digital payments (Credit Card / Online)
- Seasonal sales peaks; low months need targeted marketing
- Cancelled/Returned orders require operational review
